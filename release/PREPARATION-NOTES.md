## Meaning of time and prints
A search returns the designated occurrence, not the earliest incidental match across adjacent combinations. The full-word timestamp is the first millisecond by which all its letters have appeared. PNG and SVG exports are open to everyone after that time. UI time restrictions are artistic rules, not copy protection. Far dates have exact elapsed-time records, even where calendar export is unavailable. Calendar events are rounded upward to a whole second, with a five-minute alarm; users import them. On HTTPS deployments, events link back to the searched word. Re-upload at the same address to preserve those links.

Only a finite window is rendered. Longer words wrap across rows. PNG: 1200 x 1500; SVG: scalable text with system-font fallback, not an embedded-font archival master. Excerpts include word, UTC time and character positions. Search accepts 1–48 ASCII letters; the mathematical rule itself has no final string. Finite browser number ranges and hardware mean the implementation is not literally eternal.
